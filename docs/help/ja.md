# GuYi ユーザーガイド

[简体中文](zh-Hans.md) · [English](en.md) · [Bahasa Indonesia](id.md) · [日本語](ja.md) · [한국어](ko.md)

## 1. インストールと更新

GuYi は Apple Silicon と macOS 26 に対応しています。GitHub Releases からバージョン付き DMG を入手し、開いて `GuYi-Input-Method.pkg` を実行してください。インストーラの確認を完了後、入力欄でメニューバーから GuYi を選びます。表示されない場合は「システム設定 → キーボード → テキスト入力 → 編集」で追加してください。更新も同じ PKG で行い、通常はローカル設定が残ります。macOS に開発元を確認できないと表示された場合は、配布元を確かめた上で「プライバシーとセキュリティ → このまま開く」からそのファイルだけを許可します。

## 2. AI サービスの設定

アプリケーションから GuYi の設定を開き、「サービス」で API プロトコル、ベース URL、モデル ID、API キーを入力します。「接続をテスト」後に保存してください。Responses、OpenAI 互換 Chat Completions、Anthropic Messages に対応します。OpenAI 互換サービスは OpenAI 製品に限りません。OpenAI Responses のベース URL は `https://api.openai.com/v1` が一例です。互換サービスには提供元が指定する `/v1` などのベース URL を使い、操作パスを重複して追加しないでください。JSON Schema 出力を拒否するサービスでは「互換出力（GuYi が JSON を検証）」を有効にして接続をテストします。

追加サービスは「新規」で名前を付けて保存でき、同じプロトコルとアドレスでも別の名前付きアカウントを登録できます。既存サービスの編集はその項目だけを更新します。ローカル API 設定の読み込みは未保存のフォームを埋めるだけで、サブスクリプションや OAuth ログインから API キーを取得することはありません。ピンイン入力には API キーは不要です。

## 3. 入力モードと計算

中国語ではピンインを入力し、Space または表示された数字で候補を選びます。日本語はローマ字から仮名へ変換し、漢字辞書は含みません。韓国語は 2-Set 配列、インドネシア語と英語はラテン文字入力です。5 つの入力モードで対応する語句から絵文字候補を提示します。絵文字は選択した場合だけ入力され、ピンインのヒントは中国語入力時だけ表示されます。空欄で `5/5=` と入力すると正確な結果を候補から選べます。無効な式やゼロ除算には結果を出しません。

## 4. 翻訳とショートカット

訳文はカーソル付近に表示され、明示的に選んだものだけを挿入します。14 の翻訳対象言語を個別に有効化でき、折りたたんだ言語は翻訳を要求しません。`Option+1/2/3` は中国語／英語／インドネシア語の訳文を挿入し、ほかの言語は設定の「ショートカット」で割り当てられます。

`Option+0` は中国語・英語・インドネシア語・日本語・韓国語を順に切り替えます。`Control+Option+L` は英語と直近の非英語モードを切り替えます。初回の非英語モードはシステム言語が日本語なら日本語、韓国語なら韓国語、インドネシア語ならインドネシア語、それ以外は中国語です。Caps Lock も対応アプリで同じ切り替えを行いますが、Chrome ではシステム ABC に移る場合があります。Caps Lock 自体のシステム設定は変更しません。`Control+Option+J/K` は日本語／韓国語、`Control+Option+Return` は文章モードです。設定の「ショートカット」で各キーを変更・無効化できます。

## 5. 選択テキストの翻訳と読み上げ

通常の文章を選択すると近くに翻訳パネルが出ます。対象言語は複数選べます。訳文をコピーでき、原文や訳文の音声も再生できます。同じ言語だけの選択は初期設定で翻訳せず、数字だけのテキスト、URL、明らかな認証情報や ID も除外されます。クリック、入力、アプリ切替でパネルは閉じます。`Control+Option+T` で選択・コピー翻訳を一時停止／再開できます。

選択テキストをシステムから取得できないアプリ向けの「正確な選択範囲の互換読み取り」は初期設定で有効です。明示的なドラッグ、ダブルクリック、対応する編集欄での `Command+A` の後に限り、短時間コピーして読み取り、元のクリップボードを復元します。クリップボード履歴アプリには一時的な変更が記録される可能性があります。この機能は設定で無効にできます。「選択した原文を自動コピー」は別のスイッチで、初期設定では無効です。

## 6. 学習・キャッシュ・常用内容

本のアイコンの「読んで学ぶ」では英語・インドネシア語の語彙、発音、文法の AI による補助説明を表示します。学習対象の訳文が一つだけ展開されていれば自動で開始し、二つ展開されていれば言語を選びます。説明は辞書で検証済みとは限りません。

訳文はローカルのメモリと SQLite に期限付きでキャッシュされます。初期の保存期間は7日で、1～365日に変更、無効化、消去ができます。同じサービスアカウントでモデルや API プロトコルを切り替えても訳文を再利用し、「更新」を押すと現在のモデルで再翻訳して上書きします。異なる API アドレスやキーではキャッシュを共有しません。常用内容には文字・画像・ファイルを保存できます。

## 7. プライバシーとトラブルシューティング

有効にした翻訳は選択した API サービスへテキストを送ります。API キーとキャッシュはユーザーのローカルファイルに保存され、暗号化された保管庫ではありません。信頼できる HTTPS サービスを使ってください。安全なキーボード入力中はローカル入力のみ動作し、クラウド翻訳や選択読み取り、個人辞書の学習は一時停止します。候補が出ない場合は入力欄で GuYi が選択されているか確認し、必要ならシステム入力ソースも残してください。
