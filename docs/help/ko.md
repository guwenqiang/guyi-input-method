# GuYi 사용 설명서

[简体中文](zh-Hans.md) · [English](en.md) · [Bahasa Indonesia](id.md) · [日本語](ja.md) · [한국어](ko.md)

## 1. 설치 및 업데이트

GuYi는 Apple Silicon과 macOS 26을 지원합니다. GitHub Releases에서 버전이 표시된 DMG를 받아 `GuYi-Input-Method.pkg`를 실행하고 macOS 설치 프로그램의 인증을 완료하세요. 입력란에서 메뉴 막대의 GuYi를 선택하세요. 보이지 않으면 '시스템 설정 → 키보드 → 텍스트 입력 → 편집'에서 추가할 수 있습니다. 업데이트에도 같은 PKG를 사용하며 일반적으로 로컬 설정이 유지됩니다. macOS가 개발자를 확인할 수 없다고 표시하면 파일 출처를 확인한 뒤 '개인정보 보호 및 보안 → 그래도 열기'에서 해당 파일만 허용하세요.

## 2. AI 서비스 설정

응용 프로그램에서 GuYi 설정을 열고 '서비스'에 API 프로토콜, 기본 URL, 모델 ID, API 키를 입력하세요. 연결 테스트를 실행한 뒤 저장합니다. Responses, OpenAI 호환 Chat Completions, Anthropic Messages를 지원합니다. OpenAI 호환 서비스는 OpenAI 제품에 한정되지 않습니다. '새로 만들기'로 별도 서비스에 이름을 지정할 수 있습니다. 로컬 API 설정 가져오기는 저장 전 입력 양식만 채웁니다. 병음 입력에는 API 키가 필요하지 않습니다.

## 3. 입력 모드와 계산

중국어 모드에서 병음을 입력하고 Space 또는 표시된 숫자로 후보를 고릅니다. 일본어는 로마자를 가나로 바꾸며 한자 사전은 포함하지 않습니다. 한국어는 두벌식, 인도네시아어와 영어는 라틴 문자 입력입니다. 다섯 입력 모드에서 해당 언어의 단어에 맞는 이모지 후보를 제안합니다. 이모지는 직접 선택해야 입력되고 병음 힌트는 중국어 입력에서만 보입니다. 빈 입력란에서 `5/5=`를 입력하면 정확한 결과를 후보로 선택할 수 있습니다. 잘못된 수식이나 0으로 나누기에는 결과를 제시하지 않습니다.

## 4. 번역과 단축키

번역은 커서 근처에 표시되며 직접 선택한 번역만 입력됩니다. `Option+0`으로 중국어, 영어, 인도네시아어, 일본어, 한국어를 순환합니다. `Control+Option+L`은 영어와 마지막 비영어 입력 모드를 전환합니다. 처음 사용할 때 비영어 모드는 시스템 언어가 일본어면 일본어, 한국어면 한국어, 인도네시아어면 인도네시아어, 그 외에는 중국어입니다. 지원되는 앱에서 Caps Lock도 같은 동작을 하지만 Chrome에서는 시스템 ABC로 전환될 수 있습니다. GuYi는 시스템 Caps Lock 설정을 변경하지 않습니다. `Control+Option+J/K`는 일본어/한국어, `Control+Option+Return`은 문장 모드입니다. 설정의 '단축키'에서 모든 기능 키를 변경하거나 끌 수 있습니다.

## 5. 선택 텍스트 번역과 읽기

일반 텍스트를 선택하면 근처에 번역 창이 나타납니다. 대상 언어를 여러 개 선택하고 번역을 복사할 수 있습니다. 원문이나 번역의 읽기 버튼을 누르면 음성이 재생됩니다. 숫자만 있는 텍스트, URL, 명백한 인증 정보 및 ID는 제외됩니다. `Control+Option+T`로 선택/복사 번역을 일시 중지하거나 다시 시작합니다. 선택 텍스트를 복사해 읽는 호환 기능은 설정에서 끌 수 있습니다.

## 6. 학습, 캐시와 자주 쓰는 내용

'읽고 배우기'에는 단어, 발음, 문법에 관한 AI 보조 설명이 나옵니다. 번역은 로컬에 만료 기간을 두고 캐시됩니다. 같은 서비스에서 모델을 바꿔도 캐시를 재사용하며 '새로 고침'을 누르면 현재 모델로 다시 번역해 교체합니다. 자주 쓰는 내용에는 텍스트, 이미지, 파일을 저장할 수 있습니다.

## 7. 개인정보와 문제 해결

활성화한 번역은 선택한 API 서비스에 텍스트를 전송합니다. API 키와 캐시는 사용자 로컬 파일에 저장되며 암호화된 보관함이 아닙니다. 신뢰할 수 있는 HTTPS 서비스를 사용하세요. 보안 키보드 입력 중에는 로컬 입력만 동작하며 클라우드 번역, 선택 텍스트 읽기, 개인 단어 학습이 일시 중지됩니다. 후보가 보이지 않으면 현재 입력란에서 GuYi가 선택되었는지 확인하고 시스템 입력 소스를 예비로 유지하세요.
