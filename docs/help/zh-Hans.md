# GuYi 输入法使用帮助

[简体中文](zh-Hans.md) · [English](en.md) · [Bahasa Indonesia](id.md) · [日本語](ja.md) · [한국어](ko.md)

## 1. 安装与更新

适用 Apple Silicon/macOS 26。从 GitHub Releases 下载对应版本的 DMG，打开后双击 `GuYi-Input-Method.pkg`，按 macOS Installer 提示完成系统授权。安装器会尝试启用 GuYi；在任意实际输入框中，从菜单栏输入法菜单选择 GuYi 即可开始拼音输入。若菜单里没有 GuYi，再到“系统设置 → 键盘 → 文字输入 → 编辑”添加。使用 AI 翻译前，打开“应用程序”中的 GuYi 输入法设置并配置模型服务；拼音输入不需要 API Key。

升级使用相同的 DMG → PKG 流程；安装器保留用户目录里的服务配置、词库和缓存。若首次打开时 macOS 提示无法验证开发者，先确认文件来自本仓库；尝试打开后，在“系统设置 → 隐私与安全性”找到“仍要打开”，按系统提示只允许这一个文件。

## 2. 连接大模型服务

在“服务”页选择接口协议，填写**基础 API 地址、模型 ID 和该服务的 API Key**，点击“测试连接”后保存。读取服务可用模型只能列出服务报告的模型，不保证每个模型都支持 GuYi 的结构化翻译请求。

也可点击“载入本机 API 配置”：GuYi 只在你点击后尝试读取 Codex 的 API Key 登录配置及当前选中的 Responses 服务地址/模型，或 Claude Code `~/.claude/settings.json` 中明确设置的 `ANTHROPIC_API_KEY`、地址和模型。导入后要核对地址与模型；HTTP 地址会提示连接未加密。导入只更新未保存的表单，不自动联网或覆盖正在使用的服务；确认后自行测试、保存。ChatGPT/Claude 订阅和 OAuth 登录不能当作模型 API Key。

支持 OpenAI Responses、OpenAI 兼容 Chat Completions、Claude/Anthropic Messages。OpenAI 兼容协议不只支持 OpenAI 公司：其他服务只要实现所选接口、认证和所需输出，也可以填写其地址及模型。例如 OpenAI Responses 基础地址为 `https://api.openai.com/v1`；第三方 Chat Completions 填服务商给出的 `/v1` 地址，不要把 `/responses` 等具体操作路径重复加在地址末尾。若中转服务拒绝 JSON Schema 输出格式，可为该服务开启“兼容输出（由 GuYi 校验 JSON）”，测试通过后保存。此模式仍检查译文字段完整性，不能修复无效 Key 或未开通的模型。

豆包/火山方舟使用**云 API**，可按其支持的 Responses 或 Chat Completions 接口配置 `https://ark.cn-beijing.volces.com/api/v3`、已开通的模型 ID 或 `ep-` 推理接入点 ID，以及单独的方舟 Key；GuYi 不使用豆包桌面版登录。添加服务时点击“新建”，填写名称、协议、地址、模型和 Key，测试后保存；同协议同地址也可保存多个命名服务，并在“已配置服务”中按名称切换。编辑已有服务只更新该项，其他服务保留。旧配置会自动获得可修改的名称。切表单但未保存不会改变当前运行服务。ChatGPT 订阅、网页密码与 API Key/额度不同。

首选可信 HTTPS 服务。HTTP 虽可配置，却不加密传输密钥和原文。API Key 位于当前用户权限受限的本机**明文文件**，不是钥匙串加密；启用翻译后，相应输入/选区内容会发送到你选定的服务。

## 3. 拼音、候选与计算

中文模式输入 `nihao`，空格或数字 `1–5` 选择当前页候选。候选保持一排，按内容宽度容纳 1–5 项；左右键移动、`=`/`-` 在拼音组成时翻页，也可用 Page Up/Page Down。GuYi 会在本机学习你重复选用的词组；连续选中的单字也可逐渐组合成常用词，单字本身不会被加入词组候选。`haha` 等输入可出现表情候选。普通英文词可能作为首选候选，但不会替代所有拼音。

没有组成文本时，空格、数字和标点直接上屏。数字后的小数点、时间冒号和千分位逗号保留，例如 `1.2`、`09:30`、`3,444.50`；网址和邮箱按字面输入。拼音待转换时，Return 可原样输入字母而不附加换行。没有待处理文字时 Return 交给目标应用，在聊天或终端中可能发送/执行内容。

在空白处或空格后连续输入 `5/5=`，计算面板显示精确结果 `1`；按 Return 或点击结果才插入，不附加换行。支持加减乘除、括号、小数、千分位和 `^` 整数幂；除不尽返回精确分数。无效表达式、除零或溢出不会给出猜测结果。最长 256 字符、嵌套至多 32 层。当前公式需要在同一光标上下文连续输入。

## 4. 输入翻译与整句模式

翻译面板靠近光标，原文和已开启目标的译文分行显示；点击译文或使用可用快捷键明确上屏。`Control+Option+Return` 可切换整句模式，适合先完成较长原文再选择完整译文；输入区过长时面板内部滚动。点击语种标题可折叠译文，输入候选和划词翻译分别记住折叠状态；折叠期间不请求该语种翻译，设置里关闭的语种不显示。表情联想支持中、英、印尼、日、韩输入；输入匹配词时可明确选中表情候选，或通过输入法菜单与自定义快捷键打开系统表情面板。拼音提示仅在中文输入模式显示。整句中文模式下，待选拼音按第一次 Return 会把原始字母（如 `guyi`）放入 GuYi 原文草稿，第二次 Return 才上屏。若已选成中文，按一次 Return 上屏；英文整句也按一次 Return 上屏。不会附加换行。短语模式的拼音 Return 仍可直接原样上屏。先在不发送消息的测试框熟悉此流程。

默认 `Option+0` 在中文拼音、英文、印尼语拉丁字母、日语罗马字和韩语 2-Set 输入间循环，`Control+Option+J/K` 直达日语/韩语。日语输入提供假名转换，不含汉字词典；韩语使用标准 2-Set 键位。输入模式与译文目标语言独立。`Option+1/2/3` 对应中文/英文/印尼语译文；其他目标可在“快捷键”页单独设置。译文未就绪时快捷键不会退回给宿主插入其他符号，而会提示等待。所有功能快捷键可更换或禁用，遇到应用冲突时调整组合。Tab/Shift+Tab 保留宿主行为；Esc 取消当前组成。

首次使用时，系统中文、日文、韩文、印尼文分别默认中/英、日/英、韩/英、印尼语/英；其他系统语言暂默认中/英，已保存的输入选择优先。在支持的应用中，轻按 Caps Lock 在 GuYi 内切换英文和上次使用的非英文模式；`Control+Option+L` 是同一操作，可在“快捷键”页改键或关闭。GuYi 不修改系统的 Caps Lock 设置；Chrome 中 Caps Lock 可能切到系统 ABC。若要留在 GuYi，请使用候选框右上角的输入语言按钮或自定义快捷键。切换时，待选内容会保留在原文草稿，不提前上屏；英文默认小写，需要大写时按 Shift+字母。请保留系统输入法作后备。

## 5. 选中翻译与朗读

当 macOS 的安全键盘输入由其他应用开启时，GuYi 仍可在普通输入框使用本地输入；候选面板顶部会显示锁标记和简短说明。为避免记录或外发敏感内容，此期间暂停云翻译、选区/剪贴板读取和个人词组学习。安全键盘输入关闭后，这些功能按原设置恢复。

连续复制或暂时不需要划词翻译时，按 `Control+Option+T` 暂停，再按一次恢复；也可在 GuYi 菜单或“输入与翻译”设置中切换。快捷键可自定义。暂停时不自动翻译选中或复制的文本，原来的开关设置会保留。

拖选或双击自然语言文本后，GuYi 可在选区附近显示独立翻译面板。目标语言可多选并记住；同语种不自动翻译默认开启。混合语言按完整原文翻译；纯数字、公式、链接、明显的密码/设备码、文件路径等不会自动翻译。点击空白处、继续输入或切换应用会关闭预览。单击原文或译文行旁的扬声器可朗读，再点停止；朗读不插入文字。译文可点复制按钮，原文不提供重复复制按钮。

部分自绘应用不向 macOS 提供精确选中文字。“精确选区兼容读取”默认开启：只有用户刚拖选、双击或在支持的编辑区使用 `Command+A`，且系统读取失败时，GuYi 才尝试一次短暂复制以读取准确文本，然后恢复原剪贴板；快照无法完整恢复时放弃，不用 OCR 猜测。**剪贴板历史应用可能记录短暂变化。** 可在“输入与翻译”中关闭此功能。“选中时自动复制原文”是另一个开关，默认关闭；开启它会在翻译预览后有意把原文留在剪贴板。

文件保存对话框的文件名、普通单行编辑框、联系人搜索框和安全输入字段不自动触发选中翻译；在邮件、文档及聊天正文中选中自然语言则可使用。应用实现不同，不能保证每个自绘控件都能提供精确选区；读不到时不显示未经证实的译文。

“复制文本后翻译”是独立开关。启用后，仅用户明确复制且当前剪贴板变化时处理，不因旧剪贴板内容或粘贴而重复弹窗。密码管理器、受保护剪贴板标记及疑似凭据仍被排除。

## 6. 学习、缓存与常用内容

译文旁的书本按钮打开“读懂 · 学会用”：按需生成英语/印尼语的 IPA、关键词、语法、语气和例句。讲解为 AI 辅助，不是词典核验；修改原文会清除旧讲解。朗读使用系统该语言可用的语音，不承诺自然男/女声。

译文查询内存和 SQLite 缓存，默认 7 天，可修改为 1–365 天、关闭或清除；只缓存已开启目标的完整译文。同一服务账号、原文和翻译设置下切换模型或接口协议会复用译文；点击刷新则使用当前模型重新翻译并覆盖旧缓存。不同 API 地址或 Key 不共用缓存。网络词库可按天更新，失败时保留本地词表。个人词频学习保存在 Rime 用户词库中，不会因关闭译文缓存而删除。

“工具 → 常用内容”提供十个本机槽位，可存文字、图片或文件副本。默认 `Control+Option+数字` 复制，加 `Shift` 请求粘贴；终端的多行/附件只复制，不自动回车。单条文字上限 64 KiB，单文件 10 MiB，槽位数据未加密；不要用它存密码或密钥。

## 7. 隐私与排障

配置目录为 `~/Library/Application Support/guyi/Configuration`，服务 Key 存于其中的权限受限明文文件；词库、缓存和常用内容也只在当前用户目录。升级正常保留这些文件。缓存未加密，原文指纹索引不等于匿名化。翻译、学习会向你选定的模型服务发送对应内容，请遵守服务商数据政策。

401 通常检查 API Key；403 检查服务权限；400 检查协议/模型和结构化输出；404 检查基础地址或模型 ID；429 检查额度/限流；超时检查网络和服务。模型列表出现不代表调用成功。云端完整翻译通常仍需数秒，缓存命中不能代表网络性能。报告问题时请提供 GuYi/macOS/宿主版本、复现步骤和脱敏画面，不要附私人消息、Key 或密码。

卸载前切回其他输入法，从系统输入法列表移除 GuYi，再删除 `/Applications/GuYi输入法.app` 和 `/Library/Input Methods/GuYi输入法.app`；不要删除整个 Input Methods 目录。个人配置只在你明确需要时另行清理。
