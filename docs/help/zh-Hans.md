# GuYi 输入法使用帮助

[简体中文](zh-Hans.md) · [English](en.md) · [Bahasa Indonesia](id.md)

## 1. 安装与更新

适用 Apple Silicon/macOS 26。从 GitHub Releases 下载最新稳定 DMG，打开后双击 `GuYi-Input-Method.pkg`，按 macOS Installer 提示完成系统授权。从“应用程序”打开 GuYi 输入法设置。在“系统设置 → 键盘 → 文字输入 → 编辑”中添加 GuYi，再到真实输入框中选择它。保留系统 ABC 或其他输入法作后备。

升级使用相同的 DMG → PKG 流程；安装器保留用户目录里的服务配置、词库和缓存，不要求重启。当前是本机开发签名预览，不是 Apple Developer ID 签名或公证；如 macOS 阻止安装，不要关闭系统安全机制。安装、登记和测试编辑器通过均不能代表微信、Office 等所有应用可用。

## 2. 连接大模型服务

在“服务”页选择接口协议，填写**基础 API 地址、模型 ID 和该服务的 API Key**，点击“测试连接与翻译”后保存。读取服务可用模型只能列出服务报告的模型，不保证每个模型都支持 GuYi 的结构化翻译请求。

支持 OpenAI Responses、OpenAI 兼容 Chat Completions、Claude/Anthropic Messages。OpenAI 兼容协议不只支持 OpenAI 公司：其他服务只要实现所选接口、认证和所需结构化输出，也可以填写其地址及模型。例如 OpenAI Responses 基础地址为 `https://api.openai.com/v1`；第三方 Chat Completions 填服务商给出的 `/v1` 地址，不要把 `/responses` 等具体操作路径重复加在地址末尾。

豆包/火山方舟使用**云 API**，可按其支持的 Responses 或 Chat Completions 接口配置 `https://ark.cn-beijing.volces.com/api/v3`、已开通的模型 ID 或 `ep-` 推理接入点 ID，以及单独的方舟 Key；GuYi 不使用豆包桌面版登录。不同服务会分别保留最近一套配置；同一服务保存新配置会覆盖旧配置。切表单但未保存不会改变当前运行服务。ChatGPT 订阅、网页密码与 API Key/额度不同。

首选可信 HTTPS 服务。HTTP 虽可配置，却不加密传输密钥和原文。API Key 位于当前用户权限受限的本机**明文文件**，不是钥匙串加密；启用翻译后，相应输入/选区内容会发送到你选定的服务。

## 3. 拼音、候选与计算

中文模式输入 `nihao`，空格或数字 `1–5` 选择当前页候选。候选保持一排，按内容宽度容纳 1–5 项；左右键移动、`=`/`-` 在拼音组成时翻页，也可用 Page Up/Page Down。常用词会在本机学习；`haha` 等输入可出现表情候选。普通英文词可能作为首选候选，但不会替代所有拼音。

没有组成文本时，空格、数字和标点直接上屏。数字后的小数点、时间冒号和千分位逗号保留，例如 `1.2`、`09:30`、`3,444.50`；网址和邮箱按字面输入。拼音待转换时，Return 可原样输入字母而不附加换行。没有待处理文字时 Return 交给目标应用，在聊天或终端中可能发送/执行内容。

在空白处或空格后连续输入 `5/5=`，计算面板显示精确结果 `1`；按 Return 或点击结果才插入，不附加换行。支持加减乘除、括号、小数、千分位和 `^` 整数幂；除不尽返回精确分数。无效表达式、除零或溢出不会给出猜测结果。最长 256 字符、嵌套至多 32 层。当前公式需要在同一光标上下文连续输入。

## 4. 输入翻译与整句模式

翻译面板靠近光标，原文和已开启目标的译文分行显示；点击译文或使用可用快捷键明确上屏。日常默认短输入。`Control+Option+Return` 切换整句模式，适合先完成较长原文再选择完整译文；输入区过长时面板内部滚动。整句模式下英文输入先用 Return 确认原文，再用下一次 Return 上屏，避免误发送未写完的句子。先在不发送消息的测试框熟悉此流程。

默认 `Option+0` 切换原文语言，`Option+1/2/3` 对应中文/英文/印尼语译文；其他目标可在“快捷键”页单独设置。译文未就绪时快捷键不会退回给宿主插入其他符号，而会提示等待。所有功能快捷键可更换或禁用，遇到应用冲突时调整组合。Tab/Shift+Tab 保留宿主行为；Esc 取消当前组成。

macOS 的“使用大写锁定键切换到/离开 ABC”可用于系统输入源切换；不同应用的切换稳定性仍在验收中，请保留系统输入法。GuYi 不把大写字母模式当作系统 ABC。

## 5. 选中翻译与朗读

拖选或双击自然语言文本后，GuYi 可在选区附近显示独立翻译面板。目标语言可多选并记住；同语种不自动翻译默认开启。混合语言按完整原文翻译；纯数字、公式、链接、明显的密码/设备码、文件路径等不会自动翻译。点击空白处、继续输入或切换应用会关闭预览。单击原文或译文行旁的扬声器可朗读，再点停止；朗读不插入文字。译文可点复制按钮，原文不提供重复复制按钮。

部分自绘应用不向 macOS 提供精确选中文字。“精确选区兼容读取”默认开启：只有用户刚拖选、双击或在支持的编辑区使用 `Command+A`，且系统读取失败时，GuYi 才尝试一次短暂复制以读取准确文本，然后恢复原剪贴板；快照无法完整恢复时放弃，不用 OCR 猜测。**剪贴板历史应用可能记录短暂变化。** 可在“输入与翻译”中关闭此功能。“选中时自动复制原文”是另一个开关，默认关闭；开启它会在翻译预览后有意把原文留在剪贴板。

文件保存对话框的文件名、普通单行编辑框、联系人搜索框和安全输入字段不自动触发选中翻译；在邮件、文档及聊天正文中选中自然语言则可使用。应用实现不同，不能保证每个自绘控件都能提供精确选区；读不到时不显示未经证实的译文。

“复制文本后翻译”是独立开关。启用后，仅用户明确复制且当前剪贴板变化时处理，不因旧剪贴板内容或粘贴而重复弹窗。密码管理器、受保护剪贴板标记及疑似凭据仍被排除。

## 6. 学习、缓存与常用内容

译文旁的书本按钮打开“读懂 · 学会用”：按需生成英语/印尼语的 IPA、关键词、语法、语气和例句。讲解为 AI 辅助，不是词典核验；修改原文会清除旧讲解。朗读使用系统该语言可用的语音，不承诺自然男/女声。

译文查询内存和 SQLite 缓存，默认 7 天，可修改为 1–365 天、关闭或清除；只缓存已开启目标的完整译文。网络词库可按天更新，失败时保留本地词表。个人词频学习保存在 Rime 用户词库中，不会因关闭译文缓存而删除。

“工具 → 常用内容”提供十个本机槽位，可存文字、图片或文件副本。默认 `Control+Option+数字` 复制，加 `Shift` 请求粘贴；终端的多行/附件只复制，不自动回车。单条文字上限 64 KiB，单文件 10 MiB，槽位数据未加密；不要用它存密码或密钥。

## 7. 隐私与排障

配置目录为 `~/Library/Application Support/guyi/Configuration`，服务 Key 存于其中的权限受限明文文件；词库、缓存和常用内容也只在当前用户目录。升级正常保留这些文件。缓存未加密，原文指纹索引不等于匿名化。翻译、学习会向你选定的模型服务发送对应内容，请遵守服务商数据政策。

401 通常检查 API Key；403 检查服务权限；400 检查协议/模型和结构化输出；404 检查基础地址或模型 ID；429 检查额度/限流；超时检查网络和服务。模型列表出现不代表调用成功。云端完整翻译通常仍需数秒，缓存命中不能代表网络性能。报告问题时请提供 GuYi/macOS/宿主版本、复现步骤和脱敏画面，不要附私人消息、Key 或密码。

截图与长截图仍在开发，本版菜单、快捷键和设置入口均隐藏；请用 macOS 自带截图工具。卸载前切回其他输入法，从系统输入法列表移除 GuYi，再删除 `/Applications/GuYi输入法.app` 和 `/Library/Input Methods/GuYi输入法.app`；不要删除整个 Input Methods 目录。个人配置只在你明确需要时另行清理。
